# 🎟️ くじ 〜Qji〜

当番・順番・チーム分け・お題・罰ゲームを、その場で公平に決めて LINE で送れるツール。名前は「くじ」。英字は Qji（おくるん＝OQRN・キロっく＝kiloQ と同じ作り方で、「く」を Q にする）。GitHub Pages でそのまま動く静的サイトで、サーバーは使わない。

公開URL: https://katsuan.github.io/qji/

## 決め方（モード）

| モード | 内容 |
|---|---|
| 🎟️ くじびき | 名前から「当たりを○人」「順番を決める」「○チームに分ける」 |
| 🪜 あみだ | 名前（12人まで）とゴール。横の線は同じ高さで並ばない。上から色付きの線でなぞる |
| 🎡 ルーレット | 名前か、自分で入れた項目で回す（止まる位置は結果から決める） |
| 🔢 数字 | 範囲・いくつ出すか・1回の中で重ならないか。「前に出た数字も出さない」をオンにすると、ビンゴのように続けて引ける（出た数字は端末にためて次から外す。確かめるリンクにも外した数字を入れる。「出た数字をリセット」ではじめから） |
| 💬 お題 | 会話のお題（かるめ・じっくり・もしも）と、「1文字＋お題」（「あ」から始まる「魅力的なもの」は？ のように、ひらがな1文字とお題を一緒に引く）。中身は `data/topics.json`（`letter` に文字とお題） |
| 😈 罰ゲーム | 軽い罰ゲーム（やさしめ・もりあがる）と、やる人。中身は `data/penalties.json`。無理に飲ませる・体に負担がかかる・お金がかかるものは入れない |

名前と各モードの設定は、この端末（localStorage の `qji:state`）に残る。

## 公平さ（確かめるリンク）

引くたびにランダムな「タネ」（32bit）を1つ作り、タネと入力だけから結果を決める（乱数は mulberry32）。
「確かめるリンク」（`?r=<base64url(JSON)>`。中身は `{ m: モード, s: タネ, i: 入力, t: 引いた時刻 }`）を開くと、同じタネ・同じ条件で引き直すので、だれが開いても必ず同じ結果になる。結果の下には、タネと「同じタネと同じ条件なら、だれが開いても必ずこの結果になります」を出す。

リンクから開いた結果ページでは、決め方・入力・引くボタン・仕組みの説明を隠して結果だけを見せる（`body.is-result-page`。新しく引くときは「🎟️ 新しくくじを引く」から）。

## ヒミツで引く

「🙈 ヒミツで引く」をオンにして引くと、引いた人にも結果を見せず、カードには「🔒 結果はひらくまでヒミツ」と参加者の名前だけを出す。受け取った人がカードの「🎁 ひらく」で開くと、くじのページで「ひらく」を押したときに結果が出る（確かめるリンクに `h: 1` を入れる。だれが開いても同じ結果）。罰ゲーム・当番・お題を、グループで「せーの」で開くときに。

## おくるんで送る

「💬 LINEで送る」は、おくるんのお知らせカード（`https://liff.line.me/<LIFF ID>/card/`）に結果を渡す。ヘッダーは「🎟️ くじびきの結果」、サブタイトルは「くじ（Qji）で決めました」、色はロゴのコーラルの赤（#E23E4A）、ボタンは「🔍 くじで確かめる」（確かめるリンク）。バッジには引いたモード（例：🎟️ くじびき）と、ヒミツで引いたら「🔒 ヒミツ」、ビンゴのように続けて引いたら「🔁 続けて引く」を付ける。流入口は `from=qji`。

## ファイルの分け方

`app.js`（操作とはじめ）から ES モジュールで読む。

| ファイル | 中身 |
|---|---|
| `js/modes.js` | 決め方（モード）の一覧と小さな道具 |
| `js/rng.js` | 乱数（タネ・mulberry32・並べ替え） |
| `js/state.js` | 入力の状態・端末への保存・引けるかどうか |
| `js/draw.js` | 引く（タネと入力だけから結果を決める）・結果の文 |
| `js/link.js` | 確かめるリンク（読むときは、引くときと同じ形・範囲にそろえてから）・おくるんのカードの URL |
| `js/form.js` | 画面：決め方のボタンと、モードごとの入力 |
| `js/result.js` | 画面：結果・ヒミツの札・あみだとルーレットの図 |
| `test/` | リンクを読む・引くのテスト（`node --test test/`。`package.json` は node に js/ を読ませるためだけ） |

おくるんのカードの URL（LIFF ID）は line-share の `shared/oqrn.js` から読む。

部品（見出しの行・カード・チップ・入力欄・ボタン・開閉・トースト）はおくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`・`ui.js`。使い方はおくるんの README）。`style.css` には、くじの色と字（`:root` の `--ls-accent` など）と、くじにしかない見た目（決め方のボタン・引く！・結果・あみだ・ルーレット・ヒミツの札）だけを置く。

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`。GitHub のリポジトリ名は line-share）の `tools/brandkit.py`。pomodoro・countdown・gender-reveal・line-p2p-othello も同じものを使う）。

- Q はおみくじの筒（筒を 90 度回した向き）：六角の上の面（木の色・太い黒ふち）が輪、胴は左やや上へ伸びて白地に赤い枠の札、真ん中の穴から右下へ出たみくじ棒（赤い先）が脚
- 横長のロゴ（`logo.svg`）：みくじ棒の先を j の下の曲がりが手のように受け止める（j は棒の裏側）。j・i は Jua
- アイコン（`icon.svg` ほか）：ロゴの Q を切り出し、上の面とみくじ棒を大きく真ん中に。左上へ伸びる胴はアイコンの枠で切れる
- 共有したときの画像（`ogp.png`、1200×630）、ホーム画面に追加したとき用に `manifest.webmanifest`
